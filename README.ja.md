# Confirm New Note

[English](README.md)

新しいノートが作成される前に確認ダイアログを表示する [Obsidian](https://obsidian.md) プラグインです。

Obsidian は、まだ存在しないノートへのリンクをクリックしたときや、`Ctrl/Cmd+N` を誤って押したときに、確認なしでノートを作成します。このプラグインは作成前にダイアログを挟み、意図しない空ノートが Vault に増えるのを防ぎます。

## 機能

- **存在しないノートへのリンク**: 未解決リンク(`[[まだないノート]]`)をクリックすると、ノートが作成されて開かれる前に確認します。閲覧モード、ライブプレビュー、ソースモード、グラフビューなど、`workspace.openLinkText()` を経由してリンクを開く操作が対象です。
- **新規ノート作成コマンド**: 設定したプレフィックスで始まる ID のコマンドを、実行前に確認します。デフォルトのプレフィックス `file-explorer:new-file` で、「新規ノートを作成」(`Ctrl/Cmd+N`)と、新しいタブで作成するなどの派生コマンドが対象になります。
- **キーボード操作**: `Enter` で作成します。`Esc`、ダイアログの外側のクリック、閉じるボタンではキャンセルになります。
- **表示言語**: Obsidian の言語設定が日本語なら日本語、それ以外なら英語で表示します。

## インストール

コミュニティプラグインには登録していないため、手動でインストールします。

1. `<Vault>/.obsidian/plugins/confirm-new-note/` フォルダを作成します。
2. `main.js` と `manifest.json` をそのフォルダにコピーします。
3. Obsidian を再起動(またはプラグイン一覧を再読み込み)し、**設定 → コミュニティプラグイン** で **Confirm New Note** を有効にします。

Obsidian 1.4.0 以降が必要です。デスクトップとモバイルの両方で動作します。

## 設定

| 設定項目 | デフォルト | 説明 |
| --- | --- | --- |
| 存在しないリンクを開く前に確認 | オン | 未解決リンクをたどってノートが自動作成される前にダイアログを表示します。 |
| 新規ノート作成コマンドの前に確認 | オン | `Ctrl/Cmd+N` やコマンドパレットからノートを作成する前にダイアログを表示します。 |
| 対象コマンドIDの前方一致 | `file-explorer:new-file` | 1 行に 1 つずつ指定します。ID がいずれかで始まるコマンドすべてが対象です。 |
| デバッグログ | オフ | インターセプトした内容を開発者コンソール(`Ctrl/Cmd+Shift+I`)に出力します。 |

### ほかのコマンドを対象にする

コアプラグインやコミュニティプラグインのコマンドもプレフィックスに追加できます。

```
file-explorer:new-file
daily-notes
zk-prefixer
```

コマンド ID は、**デバッグログ** をオンにするか、開発者コンソールで `Object.keys(app.commands.commands)` を実行すると確認できます。

プレフィックスの変更は、Obsidian の再読み込み後(またはプラグインを無効→有効にした後)に反映されます。2 つのオン/オフ設定はすぐに反映されます。

## 制限事項

- 公開 API に含まれない Obsidian の内部実装(`workspace.openLinkText` と `app.commands`)に依存しています。Obsidian のアップデートで動かなくなる可能性があります。その場合は開発者コンソールに警告を出して該当する機能だけを無効にし、Obsidian 本体の動作には影響しません。
- 確認できるのは `callback` または `checkCallback` を持つコマンドだけです。`editorCallback` だけを持つコマンドはスキップします(デバッグログがオンならログに出力します)。
- リンクや対象コマンドを経由しない作成(内部 API を直接呼ぶボタンなど)は確認の対象外です。
- ダイアログは同時に 1 つしか表示しません。ダイアログ表示中に別の作成操作が発生した場合、その操作はキャンセルされます。
